# 📄 Interactive Digital Curriculum Vitae (CV)

An elegant, responsive web-based digital resume and career portfolio engineered in clean, semantic HTML5 and modern CSS3.

## 🚀 Key Highlights
- **Mobile-Responsive Architecture**: Optimized for desktop, tablet, and mobile screens.
- **Section Hierarchy**:
  - Executive Bio & Contact Details
  - Technical Skills & Stack Specializations
  - Work Experience & Solutions Architecture Achievements
  - Academic Background & Research Publications
  - Core Projects & Live Deployments
- **Print & PDF Optimization**: Dedicated `@media print` CSS stylesheet ensuring crisp 1-page or 2-page hardcopy formatting.

## 🛠️ Stack
- Semantic HTML5
- Modern Vanilla CSS3 (Custom Properties & Flexbox/Grid)
- Zero external framework dependencies
