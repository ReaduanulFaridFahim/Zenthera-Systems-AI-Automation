## 🛠️ Deployment & Setup Guide

### Option A: Production Docker Compose Stack (Recommended)

This repository includes a turnkey [`docker-compose.yml`](file:///d:/Aviation/docker-compose.yml) running the official image from [n8n-io/n8n](https://github.com/n8n-io/n8n):

```bash
# 1. Boot up the n8n cluster in the background
docker compose up -d

# 2. View container logs
docker compose logs -f n8n

# 3. Access local n8n studio at:
http://localhost:5678
```

### Option B: Native Windows Launcher (Pre-Patched)

Your repository includes a native Windows launcher pre-configured for Node v24:

```cmd
# 1. Double-click or run from command prompt:
start_n8n.bat
```
*Note: SQLite3 bindings for Windows Node v24 have been pre-compiled and verified via [`tools/patch_n8n_sqlite.ps1`](file:///d:/Aviation/tools/patch_n8n_sqlite.ps1).*

### Option C: n8n Cloud Deployment

You can run these workflows directly on your n8n Cloud instance with zero local overhead:
1. Log into your cluster: **[https://zenthrasystems.app.n8n.cloud](https://zenthrasystems.app.n8n.cloud)**
2. Click **Workflows** → **Import from File**.
3. Select any workflow from [`workflows/`](file:///d:/Aviation/workflows/).
4. Toggle to **Active**.
